# 跨项目迁移清单

## 可以作为通用核心保留

- 插件生命周期与主线程 Tick。
- TCP 连接、断线检测、请求接收与响应发送。
- 命令注册表和能力列表。
- UMG/Slate 控件查询、文本读取、点击与滚动。
- 键盘、鼠标、手柄轴和触摸输入注入。
- 通用 `UWorld`、`PlayerController`、`Pawn`、Actor Transform 查询。
- Python 客户端、超时、等待、断线重连和异常映射。
- PC、Android、iOS 设备控制抽象。
- 截图、录像、日志和性能采集抽象。

## 必须移动到项目适配层

- EM 模块以及项目角色、怪物、机关、任务引导类。
- 获取任务目标、怪物状态、机关状态等游戏语义接口。
- 项目 GM 命令、登录流程、战斗流程和副本逻辑。
- 固定地图坐标、UI 路径、文本和业务状态机。
- 项目服务器、数据库、FTP、飞书机器人和包体平台地址。

## 当前源码的重点耦合位置

| 文件 | 问题 | 处理建议 |
| --- | --- | --- |
| `01_游戏侧插件_参考实现/Source/GameAutoPlugin/GameAutoPlugin.Build.cs` | 依赖 `EM`、`UnLua`、`Lua` 等项目模块 | 通用核心只保留 UE 标准模块，项目依赖放到独立 Adapter 模块 |
| `01_游戏侧插件_参考实现/Source/GameAutoPlugin/Private/GameAPI.cpp` | 直接引用项目角色、怪物、机关和任务类型 | 改为 `IGameAutomationAdapter` 接口，由项目模块实现 |
| `02_Python驱动SDK/uedriver/commands/base_command.py` | 使用分号和结束符拼接协议 | 改为长度前缀 JSON，并加入请求 ID、协议版本和统一错误结构 |
| `05_执行与调度_参考实现/control_main.py` | 依赖固定内网服务和控制端部署方式 | 抽象 `TaskProvider`、`ArtifactStore`、`Notifier` |
| `06_角色自动化_参考示例/game_control.py` | 包含大量项目坐标和玩法判断 | 仅保留为适配示例，提炼通用等待、移动与卡住检测算法 |

## 建议的项目适配接口

```cpp
class IGameAutomationAdapter
{
public:
    virtual FString GetGameplayState() = 0;
    virtual FString GetPlayerStateJson() = 0;
    virtual FString GetEnemiesJson() = 0;
    virtual FString GetTaskTargetsJson() = 0;
    virtual FString GetInteractablesJson() = 0;
};
```

接口返回值后续应改成明确的结构体，再由协议层统一序列化，避免业务代码手工拼接 JSON。
